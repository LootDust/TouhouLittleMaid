1.3.0 更新日志

约 1278 字大约 4 分钟

2025-11-06

Bug 修正

  • 修正模型材质 UV 镜像问题
  • 修正瓜田模式不收瓜的 bug
  • 修正女仆使用神话枪械能对玩家造成伤害的 bug
  • 修正一个亘古已久的难题：玩家跨维度后，女仆神秘传送的问题
  • 修正了女仆射出的箭、三叉戟不消失的 bug
  • 修正女仆射出的弹幕会对玩家造成伤害的 bug
  • 修正跑图时崩溃的问题 #701
  • 修正部分情况下，背包数据提前加载导致的崩溃问题：#716
  • 现在女仆能够攻击恶魂了 fixed #720
  • 修正超大护甲值带来的显示问题
  • 修正了机械动力列车上 360 度旋转的问题 fixed #546

更贴合原版⻛格的修正改动

  • 女仆模组的所有实体模型、方块实体模型（包括但不限于女仆妖精、祭坛、背包等）现在都可以通过资源包进行修改了
  • 妖精女仆的可攻击目标现在可以通过数据包修改了
  • 神龛在创造模式下可以忽略复活条件
  • 绀珠之药不能附加消失诅咒和经验修复附魔
  • 消失诅咒现在可以作用于女仆，但是受 keep inventory 规则影响
  • 普通经验修复女仆主副手、护甲栏和饰品栏、P 点修复全部装备
  • 潮涌核心现在也能够对女仆起作用了
  • 添加 HanakazeT8 制作的的酒狐画
  • 大幅度修改女仆战利品项目：
    • 现在很多地方都能生成女仆的各种物品了
    • 大大减少神龛的生成概率
    • 降低 P 点的生成概率
    • 给特定物品打上稀有标签

美术资产更新

  • 更新 @kang 制作的新版美术内容，并提供内置资源包可以切换新旧两套资源
  • 添加西方 project 的模型
  • 更新新作模型和爱丽丝的玩偶模型
  • 添加更多酒狐、纸板狐、海螺模型
  • 优化蛋糕盒机制：
    • 动画更加流畅了
    • 蛋糕盒掉落物现在数据包化了
    • 蛋糕盒会自动拆掉，并有粒子效果
  • 优化祭坛设计
    • 祭坛的鸟居和御柱部分材料可以通过数据包修改了
    • 祭坛的御柱上的物品添加了动画效果
    • 祭坛有激活成功和取消激活的音效了

模组联动更新

  • 现在女仆使用 tacz 枪械时，不会被爆炸伤害了（谁才是真正的大哥？）
    • 女仆甚至能抵御爆炸带来的击退效果
    • 兼容 1.1.5 tacz 加特林动画
    • 传统女仆模型的 tacz 动画修改
    • 将冲锋枪（SMG）分类加入近距离枪械攻击范围 fixed #760
  • 添加事件，能够让其他模组支持添加额外的 GeckoLib 动画
  • 添加对 hostile-neural-networks 的兼容：可以使用妖精女仆的训练数据

其他

  • 为女仆添加寻路调试功能
  • 新增物品——主人转换工具，替代原来的结构空位来更改女仆的主人
  • 修改默认模型包的解压机制，现在的机制更利于修改和开发
  • 为无敌粒子效果添加开关
  • 现在女仆界面的二级菜单关闭后会返回女仆主界面
  • 喂食模式能够喂食超出饱食度的食物了（之前总是喂不满很难受）
  • 现在在坐垫上也能近战攻击了
  • AI 对话修改
    • 目前仅内置了一个功能：切换女仆的战斗模式
    • 能够编辑人设文件
    • 能够查看历史聊天记录
    • 能够便捷的选择 LLM 模型和 TTS 模型
    • 提供完善的错误提示机制，告诉玩家出现了什么问题，该如何修复
    • 重构 AI 对话系统，新的系统拓展性更强，玩家使用起来门槛更低
    • 添加阿里云、硅基流动网站的 STT 支持
    • 添加硅基流动、Player2 的 TTS 支持
    • 添加腾讯云、硅基流动、豆包的 LLM 支持
    • STT 现在有专门的提示音了
    • 现在历史聊天记录可以持久化了：即使退出重进存档，先前的聊天记录也会保存
    • 优化 AI 聊天 GUI 设计
    • 现在所有的女仆都能进行 AI 对话，还会自动生成人设文件
    • 完成 Function Call 的设计，现在可以通过 LLM 来执行某些游戏内容
    • 提示词优化
    • 添加 token 计数和管控功能
  • 完成全新的聊天气泡设计
    • 新的聊天气泡可以自定义背景了
    • 新的聊天气泡可以添加进度条、旋转图标、图片和能够换行的文本
    • 女仆在日常情况下会随机显示颜文字形式的聊天气泡
  • 添加并更新日语、韩语、繁体中文、越南语、印尼语、俄语、葡萄牙语等翻译
